## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| npm not found | Restart PowerShell |
| Port 5173 in use | `npm run dev -- --port 5174` |
| Port 8000 in use | `python -m uvicorn main:app --reload --port 8001` |
| CORS errors | Check backend has CORS middleware |
| Backend not responding | Check `http://127.0.0.1:8000/health` |
